# Bîrkar

Bîrkar is a personal digital studio and online space for long-form writing, notes, and projects.
Built on a modern declarative web architecture (Next.js, NestJS), it is shaped by clarity, care, and structure—designed with attention to quality, beauty, performance, security, and long-term use.

## Status

Foundation bootstrap is in progress.

## Structure

- `web/` — Next.js (public site)
- `api/` — NestJS (backend)
- `infra/` — infrastructure (later)
- `docs/` — architecture & decisions
